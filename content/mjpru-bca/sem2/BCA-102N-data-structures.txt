Q248. [Unit 5: AVL Trees, M-way Search Trees & B-Trees] (EASY)
     In a B+ tree, internal nodes act purely as:
     (A) Data storage
     (B) A routing / index search guide to direct searches to the correct leaf node

     Answer: (B)
     Explanation: Internal nodes in a B+ tree contain router keys that direct traversals to data blocks residing in leaves.

Q249. [Unit 5: AVL Trees, M-way Search Trees & B-Trees] (EASY)
     What is the primary benefit of maintaining sequential leaf links in a B+ tree?

     (B) Reduces disk file size to zero
     (C) Eliminates duplicate keys automatically
     (D) Prevents buffer overflow
     Answer: (A)

     (B) Binary Search Tree
     (C) B+ Tree
