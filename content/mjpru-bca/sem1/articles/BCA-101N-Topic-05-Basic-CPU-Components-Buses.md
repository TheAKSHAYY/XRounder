# Basic Components: Control Unit, ALU, Memory Unit & I/O Interfaces

A digital computer system functions through the coordinated interaction of four foundational hardware subsystems interconnected by the **System Bus**:

```
+----------------------------------------------------------------+
|                   CENTRAL PROCESSING UNIT                      |
|                                                                |
|  +--------------------+               +--------------------+   |
|  |    Control Unit    |               |  Arithmetic Logic  |   |
|  |     (The Brain)    |               |     Unit (ALU)     |   |
|  +---------|----------+               +---------|----------+   |
|            | Timing & Control Signals           | Operands     |
|  +---------|------------------------------------|----------+   |
|  |                   CPU REGISTERS                         |   |
|  |   [PC]   [MAR]   [MBR]   [IR]   [ACC]   [FLAGS]         |   |
|  +-------------------------|-------------------------------+   |
+----------------------------|-----------------------------------+
                             | Internal Bus
=============================v====================================
                        THE SYSTEM BUS
   ------------------------------------------------------------
   [1] ADDRESS BUS (Unidirectional from CPU to System)
   ------------------------------------------------------------
   [2] DATA BUS (Bidirectional between CPU, Memory & I/O)
   ------------------------------------------------------------
   [3] CONTROL BUS (Bidirectional Control & Strobe Lines)
=============================^====================================
                             |
         +-------------------+-------------------+
         |                                       |
+--------v-----------+                 +---------v----------+
|    MAIN MEMORY     |                 |   I/O INTERFACES   |
|                    |                 |                    |
|   RAM (SRAM/DRAM)  |                 | [Video Card / GPU] |
|   ROM (BIOS/UEFI)  |                 | [Storage Host HBA] |
|                    |                 | [NIC Ethernet Port]|
+--------------------+                 +--------------------+
```

## 1. The Control Unit (CU)
The Control Unit acts as the central conductor. It does not execute mathematical calculations; instead, it extracts instructions from main memory, decodes their binary patterns, and issues synchronized micro-operations across the datapath.

### Hardwired vs. Microprogrammed Control Units

| Feature | Hardwired Control Unit | Microprogrammed Control Unit |
| :--- | :--- | :--- |
| **Implementation** | Fixed combinational logic gates, decoders, and flip-flops | Micro-instructions stored in dedicated Control ROM |
| **Execution Speed** | Extremely fast (Gate-level propagation) | Slower (Requires microcode memory lookup) |
| **Flexibility** | Rigid; modifying instructions requires PCB re-design | Highly flexible; instruction sets updated via microcode |
| **Design Complexity** | High for complex CISC architectures | Structured and easier to debug |
| **Common Use** | RISC processors (ARM, MIPS) | CISC processors (Intel x86) |

## 2. The Arithmetic Logic Unit (ALU)
The ALU executes all arithmetic transformations and binary evaluations:
- **Arithmetic Engine**: High-speed parallel adders (Carry-Lookahead Adders), subtractors, two's complement inverters, multipliers, and dividers.
- **Logic Engine**: Bitwise boolean operations (`AND`, `OR`, `XOR`, `NOT`).
- **Bit-Shifting Unit**: Logical shifts, arithmetic shifts, and circular rotations.
- **Status Flags Register**:
  - `Z` (Zero Flag): Set when an operation produces zero.
  - `S` (Sign Flag): Set when the result is negative (MSB = 1).
  - `C` (Carry Flag): Set when an arithmetic overflow occurs out of the highest bit.
  - `V` (Overflow Flag): Set during signed two's complement overflow.

## 3. The System Bus Architecture

A bus is a shared collection of parallel conducting electrical tracks across which binary signals travel:

### 1. Address Bus (Unidirectional)
Carries the physical memory address or I/O port address that the CPU intends to access.
- **Width Determines Capacity**: A bus with $N$ address lines can uniquely address $2^N$ memory bytes.
- *Example*: A 32-bit address bus addresses $2^{32} = 4,294,967,296	ext{ bytes} = 4	ext{ GB}$. A 64-bit address bus can theoretically address 16 Exabytes.

### 2. Data Bus (Bidirectional)
Transmits actual data words and instruction opcodes between the CPU, RAM, and I/O devices.
- **Width Determines Word Size**: A 64-bit data bus moves 8 bytes in a single memory clock cycle.

### 3. Control Bus (Bidirectional)
Carries control signals and timing pulses generated by the CU:
- `MEMR` (Memory Read) / `MEMW` (Memory Write)
- `IOR` (I/O Read) / `IOW` (I/O Write)
- `READY` (Memory wait state synchronization)
- `INTR` (Hardware Interrupt Request) / `INTA` (Interrupt Acknowledge)

---

## 4. Input / Output (I/O) Interfaces

Peripherals cannot connect directly to the high-speed CPU bus due to voltage differences, mismatched data transfer speeds, and differing data encoding formats. An **I/O Interface Module** bridges this gap:
- **Isolated (Port-Mapped) I/O**: The CPU maintains distinct address spaces and specific machine instructions (`IN`, `OUT` in x86) for peripherals separate from RAM.
- **Memory-Mapped I/O**: Peripherals are assigned reserved addresses within the unified memory address map; standard memory instructions (`MOV`, `LOAD`, `STORE`) interact directly with device registers.
