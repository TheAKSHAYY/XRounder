Q_1 [Unit 1] [EASY]: According to IEEE Standard 610.12, what is the formal definition of Software Testing?
  (A) The process of analyzing a software item to detect differences between existing and required conditions and to evaluate its features
  (B) The process of writing computer code using a keyboard
  (C) The physical manufacturing of silicon microprocessors
  (D) The marketing and distribution of commercial software
Correct Answer: (A)
Explanation: IEEE 610.12 defines testing as evaluating an item to discover deviations from requirements and assess quality attributes.

Q_2 [Unit 1] [EASY]: What is the fundamental difference between an Error, a Defect (Bug), and a Failure?
  (A) An Error is a human mistake; a Defect is the flaw in code/document; a Failure is the observable deviation during runtime
  (B) They are exact synonyms in computer science
  (C) An Error is hardware; a Defect is software; a Failure is network
  (D) A Failure causes an Error which causes a Defect
Correct Answer: (A)
Explanation: A programmer commits an Error, creating a Defect/Bug in code. When executed, that defect causes a dynamic Failure.

Q_3 [Unit 1] [EASY]: What did Edsger W. Dijkstra famously state regarding the limits of software testing?
  (A) 'Program testing can be used to show the presence of bugs, but never to show their absence!'
  (B) 'Testing guarantees 100% bug-free software if automated.'
  (C) 'Testing should only be performed by the developer who wrote the code.'
  (D) 'Compilers eliminate all software errors automatically.'
Correct Answer: (A)
Explanation: Dijkstra emphasized that testing demonstrates where bugs exist, but cannot prove that zero hidden bugs remain.

Q_4 [Unit 1] [EASY]: What is the primary distinction between Verification and Validation (V&V)?
  (A) Verification asks 'Are we building the product right?' (static checking); Validation asks 'Are we building the right product?' (dynamic execution against user needs)
  (B) Verification is done by clients; Validation is done by developers
  (C) Verification is automated; Validation is manual
  (D) There is no difference between them
Correct Answer: (A)
Explanation: Verification ensures specifications and standards are met without code execution; Validation confirms the software satisfies genuine user requirements.

Q_5 [Unit 1] [MEDIUM]: What is the 'Pesticide Paradox' in software testing (Boris Beizer)?

Q_6 [Unit 1] [MEDIUM]: How does the Cost of Quality (CoQ) escalate as a defect progresses through the SDLC?

Q_7 [Unit 1] [EASY]: How does Debugging differ fundamentally from Testing?

Q_53 [Unit 2] [MEDIUM]: What is Statement Coverage in white box testing?

  (B) The number of comments written in code
  (C) The percentage of requirements listed in a document
  (D) The number of print statements in a program
Correct Answer: (A)

Q_54 [Unit 2] [HARD]: Why does 100% Statement Coverage NOT guarantee 100% Branch Coverage?
  (A) Because an `if` statement without an `else` branch can execute its body (100% statement coverage) without testing the `false` condition branch
  (B) Because statements and branches are identical
  (C) Because compilers delete branch statements
  (D) Because statement coverage only applies to Java
Correct Answer: (A)
Explanation: Consider `if (x > 0) y = 1;`. A test with $x=5$ executes all statements (100%), but completely fails to test the branch when $x \le 0$.

Q_55 [Unit 2] [MEDIUM]: What is Branch (Decision) Coverage?

  (B) Making sure every branch of a company is tested
  (C) Testing code on multiple computer branches
  (D) Executing a program on different days of the week
Correct Answer: (A)
Explanation: Branch coverage verifies that all edges in a control flow graph are traversed at least once.

Q_56 [Unit 2] [MEDIUM]: What is Condition Coverage (Predicate Coverage)?
  (A) Ensuring that each individual boolean sub-condition in a compound decision evaluates to both true and false independently
  (B) Checking the physical weather conditions during testing
  (C) Ensuring that computers have adequate air conditioning
  (D) Testing whether employees have good working conditions
Correct Answer: (A)
Explanation: In `if (A || B)`, condition coverage requires testing $A=\text{true}$, $A=\text{false}$, $B=\text{true}$, and $B=\text{false}$.

Q_57 [Unit 2] [HARD]: What is Multiple Condition Coverage (MCC)?

  (D) Writing multiple assertions in a test

Explanation: For $n$ sub-conditions, MCC tests all $2^n$ permutations, guaranteeing exhaustive logical evaluation at the cost of exponential test explosion.

Q_58 [Unit 2] [HARD]: What is Modified Condition/Decision Coverage (MC/DC)?

Q_59 [Unit 2] [HARD]: What is Path Coverage in white box testing?
